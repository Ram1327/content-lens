## 1. What this project is

A web app (and later a Chrome extension) that lets anyone check whether a piece of
content was likely generated by AI. Content types, in build order:

1. **Text** — YouTube/Instagram-style comments, blog paragraphs
2. **Images**
3. **Video** (stretch)
4. **Chrome extension** (stretch, wraps the same API)
5. **"Vibe-coded website" heuristic checker** (stretch, low confidence — no established
   research backs this one, treat it as a fun add-on, not a core pillar)

**We are NOT trying to build all 5 at once.** Text ships first, fully deployed,
before image work starts. Do not add scope to later phases without it being logged
in `DECISIONS.md` first.

## 4. Tech stack

**Frontend:** Next.js (App Router) + TypeScript, TailwindCSS + shadcn/ui, deployed on Vercel.

**Web backend:** Next.js API routes (or a thin Node service) — auth (if/when added),
rate limiting, DB reads/writes, forwards requests to the ML service.

**ML inference service:** Python, FastAPI. Exposes `POST /detect/text`,
`POST /detect/image`, etc. Deployed on Render, Railway, or Cloud Run (all free-tier).

**Database:** Supabase (Postgres) + Prisma. Stores scan history, rate-limit counters,
cached results.

**Storage:** Supabase Storage for image/video uploads.

**No paid third-party AI APIs.** All inference runs on self-hosted/open models, to
keep the whole project on free tiers. If this ever needs to change, it goes in
`DECISIONS.md` with a reason.

## 5. API contract (the seam between web and ml)

Agreed request/response shape — **do not change without updating this file and
notifying the other side**:

```json
// POST /detect/text
// request
{ "text": "..." }

// response
{
  "verdict": "ai_generated" | "human" | "uncertain",
  "confidence": 0.87,
  "model_version": "text-v1"
}

// POST /detect/image
// request: multipart/form-data with file in 'image' field
// response
{
  "verdict": "ai_generated" | "human" | "uncertain",
  "confidence": 0.94,
  "model_version": "image-v1",
  "details": {
    "format": "image/png",
    "width": 1024,
    "height": 1024,
    "artifact_score": 0.91
  }
}
```
